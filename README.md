# Smart ATM Face Authentication

## Project Overview
This project implements a cardless ATM transaction system using face detection and OTP verification to provide secure user authentication.

## Features
- Face Detection
- Face Recognition
- OTP Verification
- PIN Authentication
- Secure ATM Transactions

## Technologies Used
- Python
- OpenCV
- Tkinter

## Project Files
- face.py
- live_face468.py
- otp.py
- pin.py
- audio.py
- welcome1.py
